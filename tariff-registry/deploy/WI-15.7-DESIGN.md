# WI-15.7 Design Note

## Scope

WI-15.7 extends the existing preview deploy witness architecture to cover
`advanceEpoch`, and adds an optional seat-signature bundle loader for pilot
operator flows.

## P3 finding: witness binding happens at contract instantiation

`midnight-js-contracts` call surfaces do not expose a `witnesses` argument.
Witness injection is done by binding witnesses onto the compiled contract object
before deployment/discovery, then passing that compiled contract via
`compiledContract`.

For `tariff-registry/deploy-tariff-registry-preview.ts`, this remains:

- `CompiledContract.make(...).pipe(...)`
- `CompiledContract.withWitnesses(witnesses)`
- `CompiledContract.withCompiledFileAssets(BUILD_PATH)`

`advanceEpoch` now reuses this exact path by inserting a new approval bundle
into the same `approvalBundles` map used by `registerSchedule` and
`registerLane`.

## P2 finding: Option C signature-bundle schema

WI-15.7 chooses Option C file input for the optional loader path:

- `actionHash` (32-byte hex) and `epoch` metadata
- `signatures[]` entries each containing:
  - `seatId`
  - `signature` (64-byte Ed25519 hex)
  - `publicKey` (32-byte Ed25519 hex)

Loader behavior is fail-closed:

- parse/schema errors throw
- byte-length violations throw
- any failed Ed25519 verification throws
- fewer than threshold signatures throw

Returned data shape is the same `ApprovalBundle` consumed by the existing
`multisig_signature_valid` witness.

## H-1 concern: why not a seed-string schema

A seed-string schema would place signing secrets on operator-managed disk and
expand secret-handling blast radius in preview ceremony scripts.

Option C avoids this by accepting only public material and detached signatures:

- no seat private key ingestion in loader code
- no key derivation from operator-provided secrets
- no secret persistence in deploy artifacts

The inline deterministic signing path remains for pilot bootstrap compatibility,
but `--seat-signatures <path>` enables a path where secret keys never touch the
operator runtime.
